# 安全、版本与血缘

可信入口建立principal、tenant、clearance与策略代际。自报role/source_kind不授予权限；禁止跨tenant血缘，拒绝不得泄露另一tenant是否有目标。
派生读主体集合不得超出自身与所有derived前提的交集。来源策略收紧即时生效；放宽不能自动扩大形成时授权上限。
缓存绑定主体、tenant、策略与内容代际及请求。没有这些条件则禁用共享缓存。

## MAX与隔离

任一有效来源边unknown，或目标缺失/遗忘/不可解析，即使是旁证/矛盾边，也使当前节点MAX并隔离拒读，直至治理确认可解析前提。
只有derived递归继承敏感度。非法枚举、跨tenant、循环、摘要或revision失配须MAX并隔离拒读。
完整治理图参与安全计算，不能用用户可见的边子集计算权限。输出来源标识另行过可见性过滤。

## 纠正而非不完整的作废机制

首个核心版本禁止原地add/retract/delete改写已提交revision的边；旧版“只能追加作废边”的不完整承诺撤回。
错误通过Govern新建纠正revision表达，保留旧版本与审计。首版不接受retract事件，因此不存在未知目标预撤销或同ID跨租户误撤销。
同一revision安全下限不降；新revision的创建也不得扩大授权/降低敏感度。declassification独立授权流程尚未实现，默认拒绝。
unknown/悬空旁证不能靠清理移出安全计算。模型无持久化，须由未来治理临界区保证边集与版本不可变。

## 前提与证据版本

derived边绑定node_id、revision、content_sha。来源内容修订不静默换前提；缺失历史前提即隔离。当前策略收紧仍作用于历史版本。
核验证据绑定被核验内容摘要、revision和scope；修改内容、凭证失效或scope失配自动失去verified资格。
verified只表明符合核验规则，不证明绝对真实；核验者身份保证与独立性分开，无证据则unassessed。

## 可信输出与保留

[Context/快照输出提案](<CONTEXT_OUTPUT.md>)和[审计删除保留规划](<RETENTION.md>)提供纯谓词与反例，不实现认证、原子发送或清理。

## 边界

不防有本地完全控制权的管理员重写全部历史与密钥；无外部可信锚不声称抵抗该攻击。
时间/资源侧信道、平台级权限、真实认证和并发策略快照未实验，不声称零泄漏。

### 检索数据不授予指令权限（Issue #1）

普通写入的网页、文件、会话片段和工具返回值都是数据。允许读取、摘要匹配、来源自报或核验通过，均不是执行授权。[读取封装](<../framework/contracts.py>)以结构字段标记不可信正文；宿主不得从正文、角色自报或正文内的分隔符重建指令。尚未在真实宿主或 LLM 证明不会受记忆投毒或提示注入影响；控制字符检查不等于这种证明。

[隔离接收器](<../sandbox_runtime/source_boundary.py>)把完整校验后的成功读取交付为不可变数据帧。控制入口要求独立的进程内对象。通过[隔离读写测试](<../tests/test_source_boundary.py>)观察四类来源与同一接收器的控制计数；后项非法时前项也不交付。FixtureReceiver 不是宿主、模型或认证系统；同进程受信代码及其他消费端不在保证范围内。

### 多实例状态不等于库状态（Issue #2）

[影子库](<../shadow_runtime/store.py>)的写锁和幂等回执服务于库级事务，不是某个宿主实例的存活证明。未建立可信的实例身份、独立状态槽和新鲜度核验前，不支持由共享状态戳判断单个写者是否健康。不能确认归属时应报告未知，而非借用另一端的心跳；生产多写者状态归属尚未验收。

[隔离写者状态槽](<../shadow_runtime/writer_status.py>)由受信测试启动器按唯一写者 ID 登记，私下分发写入句柄。每个 ID 有独立的状态文件和锁；相同 ID 不允许再次登记，句柄与槽位不一致不能发布。状态回执仅含写者 ID 与序号。读取要求槽内外 ID 一致且观测未过期，缺失、损坏、时间在未来或已过期均返回 unknown。它只证明“该实例在指定时刻报告过此状态”，不证明实例此刻仍然存活。

[双进程测试](<../tests/test_writer_status.py>)让两位写者在同目录各发布十次，重新打开目录后核对写者、序号、时间和不同的状态。信任本地文件系统、时钟及启动器，不涵盖凭据轮换、接管、断电恢复、跨主机认证或任意程序修改同一目录。新事务的历史回执与审计行均绑定提交实例的 writer_id，而非读取回执的实例、操作主体或内容作者。受信启动器可传入已登记句柄；未指定时创建独立随机实例标识，不使用共享默认身份。写者不进入幂等键。无写者的旧回执不补签，旧审计行不满足新格式，不在真实库上自动迁移。回执和审计都不代替实例心跳。

### 影子库的租户布局

部署约束为一个影子库根目录服务一个租户。同租户多个写者可以共用该目录。调用方负责分配目录，当前入口未强制绑定根目录与租户。恢复时发现其他租户的审计行会报告完整性异常。
