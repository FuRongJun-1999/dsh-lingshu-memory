# 安全、版本与血缘

可信入口建立principal、tenant、clearance与策略代际。自报role/source_kind不授予权限；禁止跨tenant血缘，拒绝不得泄露另一tenant是否有目标。
派生读主体集合不得超出自身与所有derived前提的交集。来源策略收紧即时生效；放宽不能自动扩大形成时授权上限。
缓存绑定主体、tenant、策略与内容代际及请求。没有这些条件则禁用共享缓存。

## MAX与隔离

任一有效来源边unknown，或目标缺失/遗忘/不可解析，即使是旁证/矛盾边，也使当前节点MAX并隔离拒读，直至治理确认可解析前提。
只有derived递归继承敏感度。非法枚举、跨tenant、循环、摘要或revision失配须MAX并隔离拒读。
完整治理图参与安全计算，不能用用户可见的边子集计算权限。输出来源标识另行过可见性过滤。

## 纠正而非不完整的作废机制

首个核心版本禁止原地add/retract/delete改写已提交revision的边；旧版“只能追加作废边”的不完整承诺撤回。
错误通过Govern新建纠正revision表达，保留旧版本与审计。首版不接受retract事件，因此不存在未知目标预撤销或同ID跨租户误撤销。
同一revision安全下限不降；新revision的创建也不得扩大授权/降低敏感度。declassification独立授权流程尚未实现，默认拒绝。
unknown/悬空旁证不能靠清理移出安全计算。模型无持久化，须由未来治理临界区保证边集与版本不可变。

## 前提与证据版本

derived边绑定node_id、revision、content_sha。来源内容修订不静默换前提；缺失历史前提即隔离。当前策略收紧仍作用于历史版本。
核验证据绑定被核验内容摘要、revision和scope；修改内容、凭证失效或scope失配自动失去verified资格。
verified只表明符合核验规则，不证明绝对真实；核验者身份保证与独立性分开，无证据则unassessed。

## 边界

不防有本地完全控制权的管理员重写全部历史与密钥；无外部可信锚不声称抵抗该攻击。
时间/资源侧信道、平台级权限、真实认证和并发策略快照未实验，不声称零泄漏。
