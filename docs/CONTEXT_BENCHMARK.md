# C4：固定合成语料行为基准

## 复验与口径

仓根运行：

~~~text
python -X utf8 -B scripts/context_benchmark.py
~~~

[实际脚本](<../scripts/context_benchmark.py>)只读取固定[独立样例清单](<../spec/benchmark_cases.json>)和[摘要锁](<../spec/benchmark.lock.json>)；每case新建隔离内存库，不读生产/私有文件。输出完整JSON，与[已执行结果](<../spec/benchmark_result.json>)逐值比较纳入CI，不用历史绿替代当前实测。输入不是外部通用接口。manifest_sha=5016ca1a5f7b791c28e660d8e6c23dc4fa458728f93cf2cf1f7ede0406798791；transcript_sha=22ef36b2189d09fff49c6b124e329bfa231eff09948c5ed3107b93600a5c4734。报告另绑定存储、控制器及基准源码字节摘要；摘要只能证一致性，不是独立真实性证明。

39固定case：24正常样例=噪音0/10/100/1000×英文/中文/词汇不匹配×打乱种子7/29；15负例=不存在、无读取权限、跨租户、错版本、错架构、错条件、墓碑、悬空依赖、歧义、64候选截断、零calls、输出前calls不足、零bytes、零重试需要确认、零重试未命中。字节预算是读后计量的累计正文UTF8，不是硬内存/token上限。

预设状态、原因、正文/locator、text top4、动作顺序/次数/字节及完整动作trace摘要独立编写后冻结，不用SUT输出回填。fixture_sha固定生成器结果，变化会报drift，不自动刷新锁或报告。语料采用同一虚构组件双语模板与刻意同词噪音，不等价自然语料/多知识域/真实用户检索分布；这是可复验压力反例集，不是总体性能估计。

## 实际结果（每格2个打乱种子）

| 查询 | 噪音数 | 文本top4正确定位 | 显式key动作环正确就绪 |
|---|---:|---:|---:|
| 英文/中文（各自分报，均相同） | 0 | 各2/2 | 各2/2 |
| 英文/中文（各自分报，均相同） | 10 | 各0/2 | 各2/2 |
| 英文/中文（各自分报，均相同） | 100 | 各0/2 | 各2/2 |
| 英文/中文（各自分报，均相同） | 1000 | 各0/2 | 各2/2 |
| 词汇不匹配 | 0/10/100/1000（分别） | 每组0/2 | 每组2/2 |

完整12组单独读数均在报告groups。固定24正常case均正确输出已授权证据，15负例均实际报警、无事实输出，39case符合预设。**不合并为“AI可信度/答案准确率100%”。** 文本结果只表示top4包含正确locator，不表示安全作答。已知key是可信Task的显式输入，不能据其24/24声称开放语义理解成功。不取用控制项passive=NOT_RUN、calls0、evidence空，是定义上的无检索对照，不是真实模型/agent试验，不代表模型必答错。

同词噪音按排名并列及id顺序挤掉目标，是刻意构造的风险，不冒充自然平均召回；打乱输入不能改变id顺序的排序机制。该集合已知key能恢复，无key词汇不匹配仍找不到，未以key替代解答这一缺口。没有墙钟性能阈值，不宣称吞吐/延迟提升。

## 验证与反伪证据

[评价器](<../sandbox_runtime/benchmark.py>)比较精确records/body/locator、失败闭集、实际报警、冻结动作投影、完整trace摘要及语料摘要。无关dummy search、缺最后回读、同次数伪result_sha、正文/引用替换、失败夹事实、漏报警、text预期替换、语料漂移都被[独立负例](<../tests/test_benchmark.py>)拒绝。[7类评价器变异](<../tests/test_benchmark_mutations.py>)逐个在原评价器正检测/变异体漏检测双对照，证明这些检查确实发挥作用，不是穷尽证明。

总174测试本地PASS，含10项C4测试与1项覆盖7变异的测试；实际脚本子进程输出与公开报告全部逐值一致。蜂巢独立方法复核3项已落实：冻结预期且三路分报、逐case隔离并补权限/歧义/预算负例、无混合可信百分比且明确NOT_RUN。源码独立复核返回空助手轮，不计成功；有限合成实测不能替代源码安全审计。
