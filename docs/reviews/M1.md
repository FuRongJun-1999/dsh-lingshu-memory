# M1规格工具复核摘要

## 范围

本仓新写的规范与纯模型；不是生产迁移、真实掉电或全量上游回归。原rev12五项见[ADR](<../adr/0001-baseline.md>)。

## 独立复核及裁定

- 恢复专题：采纳token完整作用域、forget不释放历史、残缺历史阻止重试；将receipt与投影拆分。关于审计先正文后的假设与本设计顺序不符，不采纳。
- 血缘专题：撤销unknown/悬空旁证可能降密，因此本期禁所有原地retract；前提revision/hash与形成时授权上限固定。
- 两路较大实现复核空响应，未计为成功；改小专题重审。
- 规格小复核：严格bool/int和闭集拒绝未发现新缺陷。这不是正确性证明。
- 幂等小复核：布尔hash/非字符串身份可误过资格，已加类型检查与回归。JSON整数1与true的碰撞猜测不成立（输出字节不同）；但整数键与字符串键、tuple与list、浮点规范化的歧义成立，故请求限定为字符串键、整数型JSON对象。
- 不接受“forget后同请求幂等回执必须冲突”：同token同指纹允许返回历史receipt，但不复活投影；不同指纹始终拒绝。
- 本体复核补全所有血缘关系的DAG检查；继承仍仅derived。

## 验证范围

全规格摘要和生成物逐字检查；独立预期测试；7个模型变异；量词/右操作数/访问方向3个规格变异；文档链接/索引与公开内容、隐私扫描。
变异测试运行在临时模块，不修改仓库本体。结果由CI绑定到具体提交，不手写永久“main总是绿”。
当前运行时门禁全部NOT_RUN，详见[验收矩阵](<../ACCEPTANCE.md>)。

## 模型局限

Node/Edge是可信类型化输入，不是可直接接公网的协议解析器；hash是用于相等判定的非空标识，尚未做正文hash真实性验证。
TokenHistory是单进程顺序内存模型，不包含认证、持久化或并发。资格判断是条件谓词，不提供真实凭证验签。
规格冻结防无意漂移，不防同一维护者改规则、锁与测试。正文叙述中未编码的规则仍须人工和运行时验收。
