# 迁移计划

已有[固定旧操作候选表](<COMPATIBILITY.md>)、[条件双时间载体](<CONDITIONS_TIME.md>)与[独立规划反例](<../tests/test_migration.py>)；不覆盖所有action/参数，也不构成旧库直开支持。

这是设计，不是升级工具。生产迁移另获授权；本仓不读取真实记忆。

| 阶段 | 退出条件 | 回退 |
|---|---|---|
| S0 | 固定SHA、工具/op/权限/字段表、公开合成查询与变异锚清单 | 只读 |
| S1 | 源码文本锚改独立行为锚，原注入仍能红 | 双跑旧新测试 |
| S2 | 测试移出发布物、安装与许可验收 | 保留旧发布物 |
| S3 | 旧op到四应用契约/扩展逐项映射 | 旧适配器，不混新数据 |
| S4 | 固定内容+策略快照读影子，逐项解释安全修正差异 | 旧只读入口 |
| S5 | 隔离合成库写影子，字段/回执/恢复对账 | 丢弃隔离库，保留证据 |
| S6 | 真实门禁全部通过，授权灰度 | 已验证降级矩阵，不盲目回旧代码 |

不能无说明承诺老库直开：缺token、来源revision、授权上限的记录标legacy/unknown，不补造核验或认证。
节点格式、权限、幂等历史、审计分别版本化。回滚代码不保证回滚数据或安全语义；旧版维持不了新策略必须只读/拒绝降级。
上游持续变化，每次固定SHA与数据/策略摘要。200查询不是永恒快照；新增检索能力不能用旧bug逐位一致作为硬目标。
公开证据只用合成或授权公开数据，保留来源解释与权限断言。

## 已执行的隔离阶段检查

仓根执行 `python -B scripts/migration_gate.py`，或用 `--stage S3`、`--stage S4` 单查；未满足断言时非零退出。[门禁入口](<../scripts/migration_gate.py>)只读取固定仓内规格。S3 验的是旧版固定 SHA 的 44 个顶层候选（含扩展分类），不放行任何运行时适配器；未知操作仍拒绝。

S4 使用[固定合成夹具](<../spec/migration_shadow_fixture.json>)：旧侧为人工预设的宽松读取结果，**没有运行真实旧版**；新侧在临时目录安装一个影子记录，重新打开后执行四次读取。核对正文、定位符、策略代际、可见性、有效区间右端点及未知条件；每个差异必须对应具体原因，缺样例或错误结果夹带记录都不能通过。输出内容/策略/夹具摘要，比较完成后临时库销毁。这些结果不能作为生产迁移或发布许可。

S5 可用 --stage S5 单查：在全新临时目录写入后换实例重开，对账原始字节、权限、时间、历史回执与实际审计；同 token 异内容必须拒绝。仅在临时副本改变正文字节，核验恢复从 committed 转为 unknown 并报告完整性异常；恢复原字节后重新判定。未模拟真实断电或运行旧版；这些检查不授予真实发布许可。

### S0–S2 与 S6 的判定范围

S0 对账固定旧提交的顶层操作、当前请求字段及合成查询/权限夹具，不覆盖旧版各 action 的完整权限表。S1 实跑迁移行为测试与对应的变异测试驱动，不运行旧版软件。S2 在临时目录构造参考模块包，核对文件白名单和仓库许可原文，在独立解释器安装目录验证已知和未知操作；不是可发布的宿主插件或生产安装包。S6 单查返回 BLOCK（退出码 3）：隔离仓不接受灰度授权，不执行部署。即便发布证据齐全，授权和生产回退证据缺失仍不得推进。默认全阶段命令报告各阶段状态；其退出 0 仅表示隔离检查成功并正确报告阻断，不能作为迁移许可。
