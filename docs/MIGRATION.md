# 迁移计划

这是设计，不是升级工具。生产迁移另获授权；本仓不读取真实记忆。

| 阶段 | 退出条件 | 回退 |
|---|---|---|
| S0 | 固定SHA、工具/op/权限/字段表、公开合成查询与变异锚清单 | 只读 |
| S1 | 源码文本锚改独立行为锚，原注入仍能红 | 双跑旧新测试 |
| S2 | 测试移出发布物、安装与许可验收 | 保留旧发布物 |
| S3 | 旧op到四应用契约/扩展逐项映射 | 旧适配器，不混新数据 |
| S4 | 固定内容+策略快照读影子，逐项解释安全修正差异 | 旧只读入口 |
| S5 | 隔离合成库写影子，字段/回执/恢复对账 | 丢弃隔离库，保留证据 |
| S6 | 真实门禁全部通过，授权灰度 | 已验证降级矩阵，不盲目回旧代码 |

不能无说明承诺老库直开：缺token、来源revision、授权上限的记录标legacy/unknown，不补造核验或认证。
节点格式、权限、幂等历史、审计分别版本化。回滚代码不保证回滚数据或安全语义；旧版维持不了新策略必须只读/拒绝降级。
上游持续变化，每次固定SHA与数据/策略摘要。200查询不是永恒快照；新增检索能力不能用旧bug逐位一致作为硬目标。
公开证据只用合成或授权公开数据，保留来源解释与权限断言。
