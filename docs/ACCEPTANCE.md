# 验收矩阵

PASS / FAIL / NOT_RUN分别报告。规格工具绿不会自动更新运行时状态；必需项NOT_RUN阻止对应发布。

## 规格工具

| ID | 必需判据 |
|---|---|
| C01 | JSON重复键、未知字段、非法枚举必须拒绝 |
| C02 | 生成规范与索引逐字校验 |
| C03 | 完整规格摘要；量词/操作数/ACL方向变异均红 |
| C04 | 悬空旁证/矛盾MAX及derived下游继承 |
| C05 | 环拒绝、菱形通过、非法记录隔离 |
| C06 | tenant、主体交集、策略收紧、前提版本绑定 |
| C07 | 全无不推absent；历史与当前状态拆分 |
| C08 | 同token同指纹幂等、不同指纹拒绝 |
| C09 | 所有原地边撤销拒绝、不隐式降密 |
| C10 | 本地链接、索引、公开内容与凭据扫描 |

API提案的shape、cursor、治理、未知提交与聚合由[独立测试](<../tests/test_api.py>)和[7类API变异](<../tests/test_api_mutations.py>)覆盖；[复核裁决](<reviews/API-proposal.md>)列明未实现边界。核心冻结规范保持不变。

测试独立预期由反例编写，不能从模型输出生成。变异既要测试锁也要测试模型行为，避免只证明hash会变。
