# 项目章程

## 目标

持续维护公开的1.0架构、数据与接口契约、可执行参考模型、迁移方案和验收计划。维护者授权常规设计与公开迭代，以ADR记录取舍。
生产数据迁移、销毁、切换服务、扩大个人信息公开范围不属于自动授权。

## 约束

原文不由摘要替代；索引可重建但不能成为内容真源。来源、条件、证据、核验与身份保证分维，不用结构合规冒充事实正确。
可信入口建立主体与策略快照；role/source_kind是归因，不是认证。必需门禁NOT_RUN阻止相应发布。

## 产物三层

1. 规范：结构化规则、生成文档、ADR。
2. 规格工具：参考模型、独立样例、变异与锁检查。
3. 运行时：真实存储、并发、故障证据、宿主适配器。

当前建设前两层，第三层未实现。首个里程碑不实现生产存储、MCP/网络服务、LLM检索、签名体系、多机共识或升级工具。
测试 PASS 不跨层自动继承，不把一个提交包装成整个重构完成。
