# 架构

状态draft；可执行核心规则唯一权威为[规格](<../spec/core.json>)。

| 层 | 职责 | 禁止 |
|---|---|---|
| L3 adapters | 传输校验、可信主体、配置解析 | 绕过契约直接读写记忆 |
| L2 application | Write / Read / Govern / SelfCheck四契约 | 猜测未知或静默切换主体 |
| L1 governance | 权限、版本、血缘、生命周期、核验、审计 | 读取环境或可变全局身份 |
| L0 storage/index/rank | 原文版本、发布、索引与确定性排序 | import上层、公开无闸检索 |

L0接收不可变可见性能力与固定快照。先过滤候选再排序截断；图扩展/资料卡旁路不得例外。
底层原始读是受限系统能力，不公开给适配器。配置只在L3解析，内核标准库；密码学只定义接口，使用成熟实现。

## 真源与投影

- 不可变原文revision：内容、摘要、归因、安全标签、适用条件。
- 权限：可信治理更新的策略记录。收紧即时生效，不能只读历史宽松ACL。
- 血缘：固定来源revision与摘要，不跟随来源修订静默换前提。
- 核验证据：绑定被核验revision、hash与scope，不因旧标签继承真实性。
- payload-free审计：能证明事件，不能恢复丢失正文。
- 索引/缓存：可删重建；固定内容和策略快照下结果确定。
- metrics/trace：观测物，不参与committed/权限判断。

Write接收调用方token与完整语义请求指纹；Read返回当前授权原文；Govern追加版本与治理事件；SelfCheck逐项输出证据、未知与未执行状态。
历史提交、当前投影、当前可读性必须拆分；forget不是从未提交。

多文件原子事务、跨进程锁与快照一致性尚未实现。rename的单文件原子性不推出正文/审计/策略事务。
