# ADR-0002：真源与冻结

状态accepted-for-design。
[核心JSON](<../../spec/core.json>)是可执行规则唯一权威，文档完整生成，非关键词抽取。
重复键、未知字段、不支持的算子均拒绝。完整规范化JSON SHA256；任何内容变更硬失败，不区分所谓“仅措辞”。
锁含规格版本、摘要、前一摘要与理由。更新须reason、版本前进、同批独立评审，不静默重锁。
有写权限的人仍可同改规格/锁/测试，所以不声称防恶意维护者。需审git diff、独立复核、保护发布。
模型读取规格但只支持闭集；新语义先改规格/独立预期/ADR再扩展模型。模型不是运行时。
测试预期不可从模型自身生成；变异要证明行为测试能红，不只证明文件hash改变。
